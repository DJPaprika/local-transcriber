# 摘要调优记录

目标是让本地 Qwen2.5-7B 把一段转写稿压成能直接看的摘要。这里记下试过什么、
哪些有效、哪些是死路，免得以后重新踩一遍。

测试素材：

| 素材 | 字数 | 类型 |
|---|---|---|
| `output/bili/transcript.txt` | 8967 | 案件解说（单人口播） |
| `output/yt-demo/yt-demo.txt` | 9454 | 经济评论（作者 + 投稿者对话） |
| `苏联卫国战争胜利纪念口粮.txt` | 4172 | 开箱品尝（单人口播） |
| `output/clip40/clip40.txt` | 282 | 40 秒片段 |

## 当前配置

| 项 | 值 |
|---|---|
| 模型 | Qwen2.5-7B-Instruct Q4_K_M |
| 温度 | 0.0 |
| 上下文 | 32768 |
| 分段阈值 | 12000 字（超过才先做笔记再合并） |
| 输出结构 | 【一句话结论】【内容大意】【转写存疑处】 |

## 有效的改动

- **通用角色**：不写死领域。「输入是任意领域音视频——访谈、讲座、会议、庭审、
  教程、播客都可能」，素材跨度太大，限定领域会跑偏。
- **点名要求**：明确要求「原文点了名的物品、人名、地名、品牌、数字，在内容大意里
  要点名，不要用『各种』『一些』笼统带过」。不加这句，模型会写「介绍了各种罐头」。
- **禁止替原文做统计**：有过一次把原文「就这个默认17个呗」（说的是杯子数量）当成
  食物总数，输出「共 17 种食物」。加了「原文没数过就不许报总数」之后消失。
- **说话人归属**：双人对话必须写明谁说的。不加这句会张冠李戴。
- **存疑处附原文**：要求「每条存疑附上对应原文」，是唯一让模型真去核对的一句话。

## 试过但更差的

### 温度调到 0.1

同一素材（经济评论，9454 字）反复跑：

| 温度 | 次数 | 说话人归属 | 存疑检测 |
|---|---|---|---|
| 0.0 | 2 | 2/2 正确 | 一次 3 处真错，一次「无」 |
| 0.1 | 3 | **1/3 正确**（两次把双方立场搞反） | 3/3 报「无」 |

0.1 带来过偶然的好细节（多抓到「刘禹锡的诗句」），但把「谁主张什么」搞反的概率
升到 2/3 —— 这是最坏的错误：读起来通顺，事实是反的。**回到 0.0**。

### 分段摘要（先做笔记再合并）

把长文本切段，每段让模型抄具体名词，最后合并成文。

**更差**。一万字切三段后，细节在两次压缩里掉光，「转写存疑处」从 3 处真错变成
「无」，双人对话的结构也丢了。目前只把分段留作超过 12000 字的兜底。

### 存疑检测拆成独立调用

原本怀疑「摘要和校对在抢同一个模型的注意力」，于是拆开：

| 做法 | 结果 |
|---|---|
| 混在摘要里 | 有时抓到真错（三支箭 / 理论家 / 制度），有时报「无」 |
| 拆开 + 每 4000 字一段 | 失去全文上下文，只剩同音瞎猜：「我们」猜成「你们」、「重新增长」猜成「恢复增长」，真错一个没报 |
| 拆开 + 整篇一次 | **陷入重复循环**，同一句报二十多遍直到长度截断 |

结论：7B 只有在「先读懂全文、顺手校对」的模式下才偶尔可靠。已放弃独立校对，
`llm/tasks.py` 里的 `proofread()` 保留但没接入主流程，想再试可以直接接。

## 已知限制

- **存疑检测不可靠**：同一提示词、温度 0，两次跑可以一次 3 处、一次「无」。
  当参考，别当保证。
- **约束越多细节越少**：防幻觉和保细节在这套参数下此消彼长。约束少时细节丰富
  但可能编数字；约束多时不编了，但会概括成「多种罐头」。
- **短素材容易过度解读**：40 秒片段会把一句玩笑当成正经信息，还会补「暗示作者
  忽视了……困难」这种原文没有的推断。
